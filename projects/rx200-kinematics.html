01 · Overview

Connect joint angles to gripper poses.

For my ROB 320 kinematics project, I worked on a C++ and ROS 2 package for an RX200 robot arm. The package reads the robot’s URDF model and extracts the chain of joints from the base to the gripper.

02 · Technical approach

Solve for the gripper pose and the joint angles.

Forward kinematics combines the joint transforms to calculate the gripper’s position and orientation. Inverse kinematics finds joint angles for a requested gripper pose.

To apply the kinematics to physical pick-and-place, I defined two Cartesian targets at different positions with the same gripper orientation.

03 · Code snippet

Turn gripper pose error into joint-angle updates.

The gradient-descent solver uses the Jacobian transpose to map position and orientation error into a joint-space direction. It scales each update by how the Jacobian predicts that direction will change the gripper pose, and accepts a converged solution only if the angles are within the arm’s joint limits.

kinematics.cppC++ · Gradient-descent inverse kinematics
for (int i = 0; i < max_iter; i++) {
    auto err = poseError(chain, target_T, q);
    if (err.norm() < tol) {
        if (within_joint_limits(chain, q)) return q;
        return std::nullopt;
    }

    auto J = jacobian(chain, q);
    const Eigen::Matrix<double, 5, 1> g = J.transpose() * err;
    const Eigen::Matrix<double, 5, 1> dq =
        (err.dot(J * g) / (J * g).squaredNorm()) * g;
    for (int i = 0; i < q.size(); i++) {
        q[i] += dq(i);
    }
}
return std::nullopt;
