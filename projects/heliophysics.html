01 · Overview

Cleaning solar radio burst spectrograms for downstream machine learning.

The Helio Software Team is developing parallel data processing pipelines for NASA's SunRISE mission. I use Python techniques to clean solar burst spectrograms and support the detection and classification of solar bursts by machine learning algorithms.

The team is working on Frequency-Persistent Background Suppression, a preprocessing method that improves signal-to-noise ratio while preserving burst structure and intensity.

02 · Technical approach

Separate persistent background noise from burst-relevant structure.

Create solar burst preprocessing methods that allow for more accurate and consistent detection and classification.

Result

The current approach reports over 70% signal-to-noise ratio improvement while preserving 90% of burst structure.

04 · Code slot

Persistent frequency-band analysis for spectrogram preprocessing.

This function identifies persistent frequency bands by filtering out burst-heavy columns, estimating local background structure, and returning per-row band levels, weights, and valid columns for downstream preprocessing.

persistent_bands.pyPython · spectrogram preprocessing
def analyze_persistent_bands(S):
    # Validate that the input is a usable 2D spectrogram array.
    validate_spectrogram(S)

    # Estimate column-wise energy and remove columns dominated by burst events.
    column_energy = np.median(S, axis=0)
    col_med = np.median(column_energy)
    col_mad = 1.4826 * np.median(np.abs(column_energy - col_med)) + EPS
    valid_cols = column_energy < (col_med + BURST_SIGMA_THRESHOLD * col_mad)
    if np.mean(valid_cols) < 0.2:
        valid_cols[:] = True

    # Subtract a local frequency background to isolate persistent band structure.
    local_background = frequency_median_filter(S, FREQ_WINDOW)
    residual = S - local_background

    # Allocate one score per frequency row for band strength and temporal persistence.
    band_level = np.zeros(S.shape[0], dtype=float)
    persistence = np.zeros(S.shape[0], dtype=float)

    # Measure unusually strong residual activity row-by-row using robust MAD thresholds.
    for row in range(S.shape[0]):
        row_valid = residual[row, valid_cols]
        row_med = np.median(row_valid)
        row_mad = 1.4826 * np.median(np.abs(row_valid - row_med)) + EPS
        strong = row_valid[row_valid >= row_med + BAND_THRESHOLD_SIGMA * row_mad]
        if strong.size:
            band_level[row] = np.quantile(strong, QUANTILE)

        # Convert threshold hits into a smoothed persistence score over time.
        hits = (row_valid >= row_med + PERSISTENCE_THRESHOLD_SIGMA * row_mad).astype(float)
        persistence[row] = np.mean(
            moving_average_1d(hits, PERSISTENCE_SMOOTH_WINDOW) >= PERSISTENCE_HIT_FRACTION
        )

    # Build a local baseline and robust scale so rows can be scored relative to neighbors.
    raw_band_level = band_level.copy()
    baseline = running_median_1d(raw_band_level, BAND_WINDOW)
    radius = BAND_WINDOW // 2
    padded = np.pad(raw_band_level, (radius, radius), mode="edge")
    scale = np.array(
        [
            1.4826 * np.median(np.abs(padded[i : i + BAND_WINDOW] - baseline[i])) + EPS
            for i in range(raw_band_level.shape[0])
        ],
        dtype=float,
    )

    # Combine contrast and occupancy into final row weights for suppression logic.
    band_level = running_median_1d(raw_band_level, 5)
    contrast = np.clip((raw_band_level - baseline) / scale, 0.0, 1.0)
    occupancy = np.clip((persistence - MIN_OCCUPANCY) / max(1.0 - MIN_OCCUPANCY, EPS), 0.0, 1.0)
    weights = np.maximum(contrast, occupancy)
    weights = running_median_1d(weights, 5)

    # Flag persistent rows and guarantee they receive at least the minimum suppression weight.
    band_rows = running_median_1d((weights > ROW_FLAG_THRESHOLD).astype(float), 5) > 0.4
    weights[band_rows] = np.maximum(weights[band_rows], ROW_FLAG_THRESHOLD)
    weights = np.clip(weights, 0.0, 1.0)

    # Return the estimated band level, row weights, and usable non-burst columns.
    return band_level, weights, valid_cols
