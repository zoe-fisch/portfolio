01 · Overview

Keeping a ball-bot stable under real-world constraints.

This project combined mechanical, thermal, and electrical design to keep the ballbot within tight constraints. I built the chassis and motor mounts with laser cutting and 3D printing.

The control system used sensor feedback and a Python PID controller to maintain balance. The project pushed me to connect software, sensing, and hardware decisions as one system.

02 · Technical approach

Prototype the body, close the loop, then tune the behavior.

Problem

Allow the Ballbot to maintain balance on a ball while navigating through a remote controller.

Control strategy

Filter roll and pitch sensor data, compute balance error, apply a deadband, then update integral and derivative terms with anti-windup limits.

04 · Code snippet

PID balance error calculations.

This snippet shows the controller path from filtered state estimation to deadband handling and derivative calculation.

controller.pyPython · PID loop
# Low-pass filtering to roll and pitch
theta_x_filt = alpha * theta_x + (1 - alpha) * theta_x_filt
theta_y_filt = alpha * theta_y + (1 - alpha) * theta_y_filt

# Use filtered states for control
theta_x_ctrl = theta_x_filt
theta_y_ctrl = theta_y_filt

# Balance error
error_x = desired_theta - theta_x_ctrl
error_y = desired_theta - theta_y_ctrl

# Controller deadband
error_x = func_deadzone(error_x, ERROR_DEADBAND)
error_y = func_deadzone(error_y, ERROR_DEADBAND)

# Integral with anti-windup
integral_x += error_x * DT
integral_y += error_y * DT
integral_x = func_clip(integral_x, -INTEGRAL_MAX, INTEGRAL_MAX)
integral_y = func_clip(integral_y, -INTEGRAL_MAX, INTEGRAL_MAX)

# Derivative
derivative_x = (error_x - prev_error_x) / DT
derivative_y = (error_y - prev_error_y) / DT
